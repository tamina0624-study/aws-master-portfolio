# 12 Mask App

---

> 「障害対応中にログのスクリーンショットを Slack に貼ったら、
> ユーザーのメールアドレスや電話番号が丸見えになっていた。
> 個人情報保護の観点で大問題になりそうで冷や汗をかいた。」

> 「外部共有する資料の中に、マスクし忘れた ID が残っていた。
> 目視チェックでは見落としてしまう。」

ドキュメントやログを共有する際に機密情報を手動で消すのは、ミスが起きやすく非効率です。
テキストを貼るだけで **メールアドレス・電話番号・任意キーワードを自動検出してマスキング** するツールがあれば、見落としをゼロに近づけられます。
また、ツール自体が外部サーバーと通信しない設計（ローカル処理のみ）にすることで、入力した機密情報がツールから漏れるリスクも排除できます。

本プロジェクトは、その「貼るだけでマスクできる」ツールを Vanilla JavaScript 版と React 版の 2 実装で開発した成果です。

テキスト内の機密情報（メールアドレス・電話番号・キーワード）を自動検出してマスキングするツール。
HTML 版と React 版の 2 実装があり、すべての処理はローカルで完結し外部通信を行わない。

---

## 機能

```
┌─────────────────────────────────────────────┐
│              マスキングツール                 │
│                                             │
│  入力テキスト                               │
│  ─────────────────────────────             │
│  「担当は yamada@example.com です。         │
│   電話は 090-1234-5678 まで」               │
│                    │                        │
│                    ▼ 自動検出               │
│  ┌──────────────────────────────────┐       │

│  │  ・メールアドレス（正規表現）    │       │
│  │  ・電話番号（正規表現）          │       │
│  │  ・カスタムキーワード            │       │
│  └──────────────────────────────────┘       │
│                    │                        │
│                    ▼ マスク適用             │
│  出力テキスト                               │
│  ─────────────────────────────             │
│  「担当は *** です。電話は *** まで」        │
│                                             │
│  [クリップボードにコピー]                    │
└─────────────────────────────────────────────┘
```

## 実装バリエーション

### HTML 版（mask-app/）

## セキュリティ設計

- **外部通信なし**: 入力テキストはすべてブラウザ内で処理
- **サーバー不要**: 静的ファイルとして配布可能
- **ログ不出力**: 入力内容はどこにも記録されない
