# VPC詳細設計：パラメータ定義

| パラメータ名         | 値                  | 説明                         |
|----------------------|---------------------|------------------------------|
| VPC名                | log-leaning-vpc     | 本システム用VPC              |
| CIDRブロック         | 10.14.0.0/16        | VPC全体のアドレス範囲         |
| サブネット（Public） | 10.14.1.0/24        | パブリックサブネット1         |
| サブネット（Private）| 10.14.2.0/24        | プライベートサブネット1       |
| リージョン           | us-east-2           | 利用するAWSリージョン         |
| AZ                   | us-east-2a          | 利用するアベイラビリティゾーン|
| IGW名                | log-leaning-igw     | インターネットゲートウェイ    |
| RouteTable名         | log-leaning-public-rt| パブリック用ルートテーブル    |
| NACL名               | log-leaning-public-acl| パブリック用ネットワークACL |
| セキュリティグループ名| log-leaning-sg      | 共通セキュリティグループ      |

---

※必要に応じて、サブネットやAZを追加・拡張してください。

---

## インターネットゲートウェイ（IGW）パラメータ定義

| パラメータ名         | 値                  | 説明                         |
|----------------------|---------------------|------------------------------|
| IGW名                | log-leaning-igw     | 本VPCにアタッチするIGW名      |
| アタッチ先VPC        | log-leaning-vpc     | IGWをアタッチするVPC名        |
| タグ                 | Name=log-leaning-igw| 識別用タグ                   |

---

## ルートテーブル（Route Table）パラメータ定義

| パラメータ名         | 値                        | 説明                                 |
|----------------------|---------------------------|--------------------------------------|
| RouteTable名         | log-leaning-public-rt     | パブリックサブネット用ルートテーブル |
| 関連付けサブネット   | log-leaning-public-subnet | このルートテーブルを関連付けるサブネット名 |
| ルート1（デフォルト）| 10.14.0.0/16 → local      | VPC内通信                             |
| ルート2（外部通信）  | 0.0.0.0/0 → IGW           | インターネットへの通信                |
| タグ                 | Name=log-leaning-public-rt| 識別用タグ                           |

---

## ネットワークACL（NACL）パラメータ定義

| パラメータ名         | 値                        | 説明                                 |
|----------------------|---------------------------|--------------------------------------|
| NACL名               | log-leaning-public-acl    | パブリックサブネット用NACL           |
| 関連付けサブネット   | log-leaning-public-subnet | このNACLを関連付けるサブネット名     |
| インバウンドルール1  | 100: 0.0.0.0/0 ALL ALLOW  | 全通信許可（例：初期設定）           |
| アウトバウンドルール1| 100: 0.0.0.0/0 ALL ALLOW  | 全通信許可（例：初期設定）           |
| タグ                 | Name=log-leaning-public-acl| 識別用タグ                          |

---

## セキュリティグループ（Security Group）パラメータ定義

| パラメータ名         | 値                        | 説明                                 |
|----------------------|---------------------------|--------------------------------------|
| セキュリティグループ名| log-leaning-sg           | 共通セキュリティグループ              |
| セキュリティグループ名| log-leaning-ec2-web-sg   | EC2(Webサーバ)用セキュリティグループ  |
| アタッチ先VPC        | log-leaning-vpc           | このSGをアタッチするVPC名             |
| インバウンドルール1  | 22/tcp 192.168.1.1/32 ALLOW    | SSH許可（本番はIP制限推奨）           |
| インバウンドルール1  | 22/tcp 192.168.1.1/32 ALLOW | SSH許可（管理端末のみ許可）           |
| インバウンドルール2  | 80/tcp 192.168.1.1/32 ALLOW | HTTP許可（管理端末のみ許可）         |
| アウトバウンドルール | ALL 0.0.0.0/0 ALLOW       | 全てのアウトバウンド通信許可          |
| タグ                 | Name=log-leaning-sg       | 識別用タグ                           |
