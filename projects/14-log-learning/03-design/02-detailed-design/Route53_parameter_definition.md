# Route53 パラメータ定義

このファイルは、Webサーバー公開用のパブリックホストゾーンを前提としたRoute53のパラメータ定義例です。

## 基本パラメータ

| パラメータ名         | 値例                | 説明                                 |
|----------------------|---------------------|--------------------------------------|
| HostedZoneName       | （未定）            | 管理するドメイン名                   |
| Type                 | Public              | パブリック or プライベート           |
| Comment              | Webサーバー公開用   | ホストゾーンの用途                   |
| Tags                 | Environment=dev等   | タグ                                 |

## レコード設定例

| パラメータ名         | 値例                | 説明                                 |
|----------------------|---------------------|--------------------------------------|
| Name                 | （未定）            | レコード名（例：www）                |
| Type                 | A                   | レコードタイプ                       |
| AliasTarget          | log-learning-alb     | ALBのDNS名やエンドポイント           |
| TTL                  | 300                 | TTL（秒）                            |
| Comment              | Webサーバー公開用   | レコードの用途                       |

## 備考
- ドメイン名は未定のため、取得後にHostedZoneNameやNameを設定してください。
- ALBのDNS名をAレコードのAliasTargetとして指定することで、Webサーバー公開が可能です。
- サブドメインや他用途のレコード追加は必要に応じて追記してください。
