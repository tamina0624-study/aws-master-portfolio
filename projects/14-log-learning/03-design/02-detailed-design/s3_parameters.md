# S3詳細設計：パラメータ定義

| パラメータ名         | 値                        | 説明                                 |
|----------------------|---------------------------|--------------------------------------|
| バケット名           | log-learning-logs          | ログ保存用S3バケット名               |
| リージョン           | us-east-2                 | バケット作成リージョン                |
| バージョニング       | 有効                      | オブジェクトのバージョン管理          |
| 暗号化               | SSE-S3（サーバー側暗号化）| デフォルトのサーバーサイド暗号化      |
| ライフサイクル       | 365日後に自動削除         | ログ保存期間の自動管理                |
| パブリックアクセス   | 全てブロック              | セキュリティ対策                      |
| アクセス制御         | バケットポリシー           | 必要なIAMロール・ユーザーのみ許可      |
| タグ                 | Name=log-learning-logs     | 識別用タグ                           |

---

※要件に応じてライフサイクルやアクセス制御を調整してください。
