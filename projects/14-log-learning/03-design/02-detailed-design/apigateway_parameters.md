# API Gateway詳細設計：パラメータ定義

| パラメータ名         | 値                              | 説明                                 |
|----------------------|---------------------------------|--------------------------------------|
| API名                | log-learning-api                 | ログ処理用API Gateway名              |
| タイプ               | HTTP API                        | シンプルなAPI構成（RESTも可）        |
| エンドポイントタイプ | REGIONAL                        | リージョン内エンドポイント           |
| ステージ名           | prod                            | デプロイ先ステージ                   |
| リージョン           | us-east-2                       | 配置リージョン                        |
| Lambda統合           | log-learning-log-handler         | バックエンドLambda関数名              |
| 認証                 | IAM認証/なし（用途に応じて選択）| APIアクセス制御                      |
| ログ出力             | 有効（CloudWatch Logs）         | アクセスログ・実行ログの有効化        |
| タグ                 | Name=log-learning-api            | 識別用タグ                           |

---

※要件に応じて認証方式やエンドポイントタイプ等を調整してください。
