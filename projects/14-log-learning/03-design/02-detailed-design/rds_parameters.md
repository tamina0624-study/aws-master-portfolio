# RDS詳細設計：パラメータ定義

| パラメータ名         | 値                              | 説明                                 |
|----------------------|---------------------------------|--------------------------------------|
| DBインスタンス識別子 | log-learning-db                  | RDSインスタンス名                    |
| エンジン             | MySQL                           | データベースエンジン                 |
| エンジンバージョン   | 8.0                             | DBエンジンのバージョン               |
| インスタンスタイプ   | db.t3.micro                     | テスト・学習用の小型インスタンス     |
| ストレージタイプ     | gp2（汎用SSD）                  | ストレージ種別                       |
| ストレージサイズ     | 20GB                            | 初期割当サイズ                       |
| マルチAZ             | 無効                             | 単一AZ構成（学習用途）               |
| VPC                  | log-learning-vpc                 | 配置先VPC                            |
| サブネットグループ   | log-learning-db-subnet-group     | DB配置用サブネットグループ           |
| セキュリティグループ | log-learning-db-sg               | DB用セキュリティグループ             |
| バックアップ保持期間 | 7日                             | 自動バックアップの保持日数           |
| 自動バックアップ     | 有効                             | 障害対策用                           |
| パブリックアクセス   | 無効                             | インターネットからの直接接続不可     |
| タグ                 | Name=log-learning-db             | 識別用タグ                           |

---

※要件に応じてエンジン・インスタンスタイプ・ストレージ・バックアップ等を調整してください。
