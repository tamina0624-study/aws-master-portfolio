# IAM Access Analyzer 学習結果

## 実施内容

IAM Access Analyzer を有効化し、動作確認を行った。

確認できた内容は以下の通り。

- 未使用のユーザー、アクセスキー、権限を一覧で確認できる
- 外部アクセスが許可されている設定を一覧で確認できる

## 気づき

未使用ユーザーは IAM User や Role の画面でも確認できるが、使用していない権限まで絞り込める点は、最小権限の実現に有効だと感じた。

外部アクセスの調査については、Network Access Analyzer でも似たことができる。用途の住み分けは次の通り。

- IAM Access Analyzer: 権限の確認
- Network Access Analyzer: ルーティング、ACL、SG などの到達性の確認

## 所感

想定より早く結果を確認できた。コストは発生するが、設定はそれほど難しくなく、すぐに状況を把握できる点が良い。
