# 12 Mask App

テキスト内の機密情報（メールアドレス・電話番号・キーワード）を自動検出してマスキングするツール。
HTML 版と React 版の 2 実装があり、すべての処理はローカルで完結し外部通信を行わない。

---

## 機能

```
┌─────────────────────────────────────────────┐
│              マスキングツール                 │
│                                             │
│  入力テキスト                               │
│  ─────────────────────────────             │
│  「担当は yamada@example.com です。         │
│   電話は 090-1234-5678 まで」               │
│                    │                        │
│                    ▼ 自動検出               │
│  ┌──────────────────────────────────┐       │
│  │ パターンマッチング               │       │
│  │  ・メールアドレス（正規表現）    │       │
│  │  ・電話番号（正規表現）          │       │
│  │  ・カスタムキーワード            │       │
│  └──────────────────────────────────┘       │
│                    │                        │
│                    ▼ マスク適用             │
│  出力テキスト                               │
│  ─────────────────────────────             │
│  「担当は *** です。電話は *** まで」        │
│                                             │
│  [クリップボードにコピー]                    │
└─────────────────────────────────────────────┘
```

---

## 実装バリエーション

### HTML 版（mask-app/）
- Vanilla JavaScript で実装
- 依存ライブラリなし、単一ファイルで動作

### React 版（react/）
- コンポーネント分割による保守性向上
- カスタムキーワードの追加・編集・削除 UI

## セキュリティ設計

- **外部通信なし**: 入力テキストはすべてブラウザ内で処理
- **サーバー不要**: 静的ファイルとして配布可能
- **ログ不出力**: 入力内容はどこにも記録されない
