# AWSログ学習の進め方（実践フロー例）

1. 対象サービスの作成
   - 例：EC2, S3, Lambda, API Gateway, VPC, RDS, ELB, Route53, WAF, GuardDuty など
2. 各サービスのログ出力先を設定
   - CloudWatch Logsが利用可能なものはCloudWatchを指定
   - S3出力が必要なものはS3バケットを用意し設定
3. 各種ログフォーマットを確認
   - 実際に出力されたログファイルの形式（JSON, CSV, テキスト等）を確認
4. 可視化の設定
   - CloudWatch Logs InsightsやAthena、QuickSight等で可視化・クエリ設定
5. 障害発生のシミュレーション
   - 各サービスで意図的にエラーや異常を発生させる（例：認証失敗、通信遮断、リソース枯渇など）
6. ログから障害内容を確認
   - 発生した障害がどのログに、どのように記録されているかを確認
   - ログ検索・抽出・可視化の手順を実践

---

この流れを繰り返すことで、AWS各種ログの実践的な運用・トラブルシュート力が身につきます。
